# SEO and Google indexing checklist

The project includes a title, description, author, canonical URL, social preview metadata, Person structured data, `robots.txt` and `sitemap.xml`.

Before requesting indexing:

1. Deploy the site and confirm the final public URL.
2. Replace the sample `pages.dev` URL in `src/data/site.ts`, `index.html`, `public/robots.txt` and `public/sitemap.xml` with the real production URL.
3. Open Google Search Console and add the website property.
4. Verify ownership using one of the verification methods provided by Search Console.
5. Submit `/sitemap.xml` in Search Console.
6. Use URL Inspection to request indexing of the homepage.
7. Keep project descriptions, article pages and profile details accurate and useful. Indexing and search ranking are controlled by Google and are not guaranteed.
